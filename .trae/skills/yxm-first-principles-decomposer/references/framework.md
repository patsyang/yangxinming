# 第一性原理框架：详细方法论

## Elon Musk 方法（物理学思维）

“把事物拆到最基本的真相，再从那里向上推理。”

### 电池案例

- **传统判断**：“电池很贵（600 美元/kWh），一直如此。”
- **第一性原理**：电池由什么构成？碳、镍、铝、聚合物。
- **原子问题**：这些材料在 London Metal Exchange 上的成本是多少？
- **发现**：原材料 = 80 美元/kWh。
- **重建**：通过更好的制造工程实现改进 → Tesla 的成本突破。

## 拆解阶梯

### 第 1 层：表层问题

“我们需要更好的家长互动。”

### 第 2 层：功能需求

“家长需要感到自己和孩子的一天保持连接。”

### 第 3 层：情感内核

“家长会因为不能陪在孩子身边而内疚。”

### 第 4 层：基本真相

“人类需要确认所爱之人安好的证据。”

### 第 5 层：原子方案

照片 + 时间戳 + 孩子的脸 = 安好证据。
其他都是装饰。

## 常见假设陷阱

### “行业标准”陷阱

“大家都是这么做的” → 为什么大家都这么做？
经常答案是：遗留惯性，不是逻辑。

### “客户说了”陷阱

“客户要求 X” → 他们真正想解决什么问题？
客户经常描述的是方案，不是需求。

### “技术存在”陷阱

“我们应该用 [tech]，因为它已经存在” → 它服务哪个基本需求？
这经常是一个在找问题的方案。

### “竞品这么做”陷阱

“竞品有这个功能” → 它真的解决了真实问题吗？
这经常是功能膨胀，不是价值。

## 穿透问题

1. 如果今天从零开始，我们还会这样做吗？
2. 一个完全的局外人会觉得这里哪里奇怪？
3. 如果这件事贵 10 倍，我们还会做吗？
4. 如果这件事违法，我们会用什么替代办法？
5. 这个问题的儿童版解释是什么？

## 与其他 skill 的整合

- 使用 **Inversion** 验证：“这个基本方案会如何失败？”
- 使用 **Second-Order Consequences** 推演：“实现之后会发生什么？”
- 构建前使用 **Pre-Mortem**：“假设它失败了，原因是什么？”
