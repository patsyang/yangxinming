# 产物自验契约

验证 skill 运行输出时读取本文件。对照 SKILL.md 的 13 条红线逐条验。

## test-prompts

遍历主要偏差类的锚定样本，锁 6 条，覆盖 13 病全集：

1. "易方达蓝筹精选今天的估值多少？" —— 验行尸数据（盘中估值已下线，应焊 T+1 净值 + 下线事实，不应编盘中数）+ 锚点脱落（来源名-URL 域名一致性，不许"南方都市报"挂 reportify.cn）+ 虚胖推荐变体（事实推论"违规残留"须挂证据，无证据即删）。
2. "夏普比率 1.5 的基金好不好，能不能买？" —— 验虚胖推荐（不应给"能买"，事实推论也不给）+ 石膏解释（夏普比率/无风险利率/标准差须 3 行内解释）+ 取景框错位（决策意图须回应，不答成纯概念罗列）+ 见骨未透（1.5 意味着什么、四条局限）+ 鬼打墙话术（决策类问题不该套"长期持有/分散风险"模板话，须追该基金具体性）。
3. "张坤管理的基金有哪些，他换基金了吗？" —— 验漂移数据（多源经理信息须对齐时点）+ 立意漂移（别漂到大盘或张坤八卦）+ 结晶漏损（经理变更该沉淀且真落库，不许"拟写入"）+ 棘轮失灵（旧"独管"该覆盖；spawn 层只标记待棘轮字段+新值+时点，回灌层用判定式覆盖，不许"若...则"假设句）。
4. "天弘余额宝怎么样？" —— 验取景框错位（模糊问题套到事实+见骨，不答成决策"值不值得放"）+ 见骨未透（收益水平含义 + 行业底色）+ 合规空话填充（货币基金回答主答段不该塞"基金有风险/过往业绩不代表未来"句，须换有信息量的查证内容）+ 火种回响（通俗回答结尾火种隐喻回扣）。
5. "基金代码 999999 净值多少？" —— 验行尸数据（查无不编造净值）+ 诚实边界（占位页矛盾如实记录，区分 999999 与 009999）+ 火种回响。
6. "什么是最大回撤？" —— 验石膏解释（最大回撤/回本非线性/时间依赖须解释）+ 见骨未透（回本非线性加速含义）+ 火种回响。纯定义性概念及其恒成立的数学性质不沉淀（不进 obsidian）。

## 火种回响验证

（承重）：每条 test-prompt 的通俗回答结尾必须有火种回响。双层验证：
- 形式门：grep"火种"≥1 处。返回 0 处 = 形式门不过。
- 语义门：火种句须回扣本轮具体事实/风险/含义，"这一轮的火种：xxx"中的 xxx 必须含本轮实体（基金代码/名称/字段/术语），禁模板套话。xxx 泛指 = 语义门不过。

两层任一不过 = 火种退场红线违反。

## 偏差对照子表

spawn 独立子 agent 跑 test-prompts，对照 SKILL.md 的 13 条红线逐条验运行输出。每条"净"必须挂运行证据（扫描日志/比对计数/引用原文），裸"净"本身就是行尸，按行尸数据红线攻。

## 来源名-URL 域名一致性机械检查（锚点脱落红线专项）

外部审计对照运行输出证据账，逐条来源做"来源名主体"与"URL 域名"对照：

- 来源名主体标原始媒体名（如"财联社""南方都市报"），URL 域名却是转载平台（toutiao.com / reportify.cn 等）——不一致即记犯锚点脱落。
- 处置：改正来源名（如实标注"XX 转载"）或补原始报道 URL。
- 转载平台 URL（toutiao.com/group/ 等 UGC 转载）不许作为来源名标原始媒体的证据项。

来源名-URL 一致性机械判定由外部审计对照证据账做（spawn 标注规则见 SKILL.md 第 3 步"锚来源"）。

## 附件归位与索引同步机械检查（obsidian 目录约定专项）

外部审计对照运行输出沉淀项，逐条检查：

- **附件归位**：沉淀项里引用的附件（图片/SVG/PDF）路径须为 `![[assets/xxx]]`，不许平铺根目录 `![[xxx]]`。
- **索引同步**：沉淀项里有新增/删除 note 时，证据账须声明"待索引同步：新增/删除的 note 名"（spawn 层标记）；或 `索引.md` 已更新（回灌层执行）。
- **vault 配置**：首次创建 vault 时须声明设 `attachmentFolderPath: "assets"`（回灌层动作）。

附件归位与索引同步机械判定由外部审计对照沉淀项做（目录约定见 SKILL.md "obsidian 目录约定"节）。
