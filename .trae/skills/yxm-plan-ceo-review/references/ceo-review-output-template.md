# CEO 评审输出模板

`plan-ceo-review` 必须使用中文结构化输出。不要输出散文式鼓励，不要只列建议。用户读完后必须知道下一步该做什么、要回答什么、补什么材料。

协议名、命令名和文件名可以保留英文；面向用户的标题、结论值、评审模式、行动建议和问题必须使用中文。模板正文直接使用中文，不要输出英文枚举表。

允许的结论值只有：批准推进、有条件批准、需要修改后再评审、延期、否决。

允许的评审模式只有：放大野心、选择性增强、锁范围严审、收缩或否决。

允许的范围决策只有：加入、暂缓、拒绝、保留、删除。

## 输出顺序

最前面必须先回答用户关心的行动问题：

1. 我现在该做什么。
2. 我该回答哪些问题。
3. 哪些问题最少回答完就能继续推进。

如果 verdict 不是“批准推进”，不能只输出问题列表，必须给出一条最短补齐路径。

## 缺上下文时

如果信息不足，先输出：

```text
## 你下一步要做什么
先补齐下面 2-3 个问题；补完后我可以重新判断是否能推进。

## 你需要回答的问题
1. ...
2. ...
3. ...

## 已知事实
- ...

## 缺失事实
- ...

## 暂定假设
- ...
```

然后仍然给出临时结论。缺少 hard gate 时，临时结论通常应为“需要修改后再评审”。

## 标准输出

```text
## 你下一步要做什么
- <一条最推荐动作，必须能直接执行>
- <如果需要补材料，说明补到哪里：PRD 哪一节、评审回复、指标表或实验计划>

## 你需要回答的问题
1. <最高优先级问题，最好是选择题或可填空问题>
2. <第二优先级问题>
3. <第三优先级问题>

## 评审结论
结论：批准推进 / 有条件批准 / 需要修改后再评审 / 延期 / 否决
置信度：<0-100>
评审模式：放大野心 / 选择性增强 / 锁范围严审 / 收缩或否决

一句话判断：<为什么这个计划现在应推进、应修改、应延期或应否决>

## 阻塞缺口
- <缺失的 hard gate 或阻塞项；必须写成可关闭动作>

## 不建议现在做的前三个理由
1. <反方理由>
2. <反方理由>
3. <反方理由>

## 关键假设
- <影响结论的关键假设>

## 证据表
| 判断项 | 当前证据 | 可信度 | 缺口 |
| --- | --- | --- | --- |
| 目标用户 | ... | 高/中/低 | ... |
| 痛点强度 | ... | 高/中/低 | ... |
| 业务价值 | ... | 高/中/低 | ... |
| 验证路径 | ... | 高/中/低 | ... |

## 范围决策
| 项目 | 决策 | 理由 |
| --- | --- | --- |
| <scope item> | 加入 / 暂缓 / 拒绝 / 保留 / 删除 | ... |

## 修订后的计划
1. <阶段或动作>
2. <阶段或动作>
3. <阶段或动作>

## 最小验证实验
- 目标假设：...
- 实验方式：...
- 成功指标：...
- 失败阈值 / 停止标准：...
- 时间盒：...

## 需要拍板的决策
- <需要用户立即拍板的问题>
```

## 批准时的额外要求

当结论为“批准推进”或“有条件批准”时，必须增加：

```text
## 为什么现在值得投入
- <为什么现在值得投入>
- <为什么不是以后>
- <为什么这件事比其他机会更优先>
```

“有条件批准”必须把条件写成可检查项：

```text
## 批准条件
- [ ] <条件，必须可验证>
```

## 不批准时的额外要求

当结论为“需要修改后再评审”“延期”或“否决”时，必须增加：

```text
## 重新评审的最短路径
- <最小补证或改 scope 路径>
```

“否决”必须给出更好的替代动作：

```text
## 更好的替代动作
- <不做该计划后应该做什么>
```

## 问题写法要求

- 每个问题必须让用户知道如何回答，避免只写“是否补充某某”。
- 优先写成“请给出 A/B/C 中的选择和一句理由”或“请补 1-3 个真实样本”。
- 一轮最多放 3 个最高优先级问题；其他问题放到“后续再问”或“阻塞缺口”。
- 不得把 `Required Decisions` 这种英文标题直接输出给用户。
- 不得把英文枚举或英文术语作为主表达；应使用“需要修改后再评审”“锁范围严审”“停止标准”等中文表达。

## 风格要求

- 直接、具体、可决策。
- 优先写事实、缺口、取舍和下一步。
- 不用“整体不错”“建议优化”“可以考虑”这类无判断表达。
- 每个阻塞项必须能被用户行动关闭。
- 每个指标必须尽量包含定义、数据来源、统计周期和阈值。
