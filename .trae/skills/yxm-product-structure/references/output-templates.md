## 技术落地映射

技术落地映射应该说明：

```text
哪些产品对象必须成为数据对象
哪些状态必须被系统表达
哪些模块之间有事件关系
哪些判断需要留痕
哪些环节需要同步处理
哪些环节可以异步处理
哪些地方需要人工确认
哪些地方适合 Agent 自动化
哪些边界可以成为后续服务边界候选
```

不要输出：

```text
数据库表字段
API URL
消息队列选型
具体框架
部署拓扑
```
