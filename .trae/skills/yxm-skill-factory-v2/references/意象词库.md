# 意象词库

承重的认知锚点，不是装饰。它首先是压缩工具——一个词能替掉一段解释才用；但它更是认知锚点——每个词都钉住一个"指令化退化病"，LLM 一退化就被这个词拽回承重点。**用了反而要加注释，不如不用。** 女娲造 skill 时翻它找压缩词，更翻它给 skill 配认知锚点；哪吒守尖锐时用它判断"这段能不能一个词替掉、能不能锁住一个承重判断"。不强制——自然语言优先，词库是弹药。

## 火 / 熔铸
- **熔炉** — 多源烧炼到只剩骨头再重生（不是压扁成摘要）
  - 治：多源信息被压扁成摘要，而非烧炼到骨头重生
- **火种** — 值得点燃、能让其他判断围着它转的种子
  - 治：使命核心被"本质关键点"式指令词替换，LLM 失去感觉
- **焊** — 两个东西强绑、不可分离
  - 治：两个该强绑的东西被指令式"需关联"弱化
- **结晶** — 散乱信息凝成可复述的核
  - 治：散乱信息被指令式"已整理"当收敛

## 骨 / 身体
- **剔骨** — 砍掉不该存在的，让剩下的按正确力线重长
  - 治：该砍的不砍，靠堆量撑完整
- **虚胖** — 有壳无核、靠堆量撑着的假完整
  - 治：靠堆量撑完整，被"内容丰富"当价值
- **行尸** — 写着活的、跑着死的
  - 治：机制写着活但没跑，被指令式"已收敛"声明掩盖；亦治把"行尸"隐喻替换成"禁止只审设计"的指令化退化
- **见骨** — 切到露出结构，不停在表面
  - 治：分析停在表面，被"已阐述"当深度
- **石膏** — 产物表面完整、内里空洞，敲起来是壳子声
  - 治：产物被"字段齐全"当承重，实则无核

## 力 / 工具
- **凿子 / 钉子** — 问是凿（刺穿表面）、答是钉（把判断固定到位）
  - 凿子治：问句被指令式"需澄清"弱化，不刺穿表面
  - 钉子治：答句被指令式"需说明"弱化，不固定判断
- **杠杆** — 小输入撬动大输出
  - 治：小输入撬大输出的设计被指令式"需扩展"稀释
- **棘轮** — 单向止回、只保留改进
  - 治：改进不单向止回，被指令式"可回退"掩盖退化
- **承重** — 判断 / 假设是否实质，能否撑住后续推理
  - 治："所有机制同等重要"的指令式平权，掩盖真承重

## 方向 / 动作
- **穿透** — 穿过表层、不可逆地抵达下层
  - 治：分析被指令式"已分析"弱化，不可逆抵达下层
- **坍缩** — 有结构的判断退化成更低维的廉价形式（防坍缩）
  - 治：有结构的判断被指令式"已简化"退化成低维廉价形式
- **漂移** — 两个本该同步的东西随时间慢慢错位
  - 治：两个该同步的东西被指令式"需对齐"掩盖错位
- **收束** — 把发散信息收敛到一个能被复述的核
  - 治：发散信息被指令式"已归纳"当收敛，未到可复述的核

## 场景 / 结构
- **裂缝** — 表面连贯下隐藏的张力，正是价值生长点
  - 治：表面连贯的产物被指令式"已覆盖"掩盖隐藏张力
- **锚点** — 单一参照物锁住全文语境，换锚点 = 换地图
  - 治：全文语境被指令式"需统一"弱化，无单一参照物锁住
- **鬼打墙** — 没追到根，原地循环
  - 治：没追到根的循环被指令式"已处理"掩盖
- **取景框** — 结构形状决定呈现框架，而非反过来套模板
  - 治：结构形状被指令式"按模板"套，而非反过来
