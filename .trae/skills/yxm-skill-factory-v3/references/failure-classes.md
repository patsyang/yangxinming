# 检查类偏差库（bias-library: inspection）

`bias-libraries` 的第一个注册实例——**检查/审计/校验/审查**类 skill 的偏差库。鲁班反向轴的源、判官攻检查类产物运行输出时的对照表。**单一事实源（检查类范围内）**——检查类的通用偏差唯一权威是本文件；鲁班图只**引用**它（标注"见 failure-classes.md"，不复制内容），判官对照时通用偏差查这里、域偏差查鲁班图。一处源，不复制，不矛盾。

> 这是**检查类**的偏差库（注册约定、其他类型索引见 `bias-libraries.md`）。生成/创作类库是 `generation-bias.md`，行动/编排类库是 `action-bias.md`——不套本库。

## 它治什么病

判官可能把某个具体失败（如"同一指标两处数值不一致"）当探针记下来，造出的 skill 却还是漏了这类失败。根因两层，这库治第二层：

- 第一层（断 channel）：判官只攻设计稿不攻产物运行输出——**重定向可解**，见各 persona。
- 第二层（偏差类型学缺失）：判官和鲁班的产出里没有"偏差"这一维内容——**重定向补不回**。判官攻输出时手里只有零散探针，对没记过的偏差（如占位符残留）攻不到。这库补这一维。

判官有这库，攻输出时**逐类对照**："我这里 N 类偏差模式，你的输出对每一类都验过了吗"——这是"靠记忆碰运气"换不来的系统性覆盖。

## 适用范围

本库服务**检查/审计/校验/审查/lint/review** 类 skill——价值在于穷尽一个有限检查空间。**生成/创作类、行动/编排类 skill 的偏差是另一套**（生成类：套路化、洞察停在表面；行动类：副作用、不可逆风险），不套本库——它们的偏差库是 `generation-bias.md`、`action-bias.md`（索引见 `bias-libraries.md`）。

## 种子（检查类内域无关）

**只放换一个检查域照样成立的通用偏差模式。** 不写某个具体业务域的特征词——域特定失败归鲁班当次的 per-mission 图，不进这里。这是这库不退化成"某次漏报纪念碑"的全部支点。

每类 = 偏差模式名 + 它是什么 + 怎么落地为一个操作。措辞域中性：

- **内部数值矛盾** — 同一属性两处值打架（与外部锚点无关）。操作：抽取所有同类数值，两两比对，标记不等对。
- **占位符 / 未填残留** — 占位标记没替换（如 `[XXX]` / `_______` / `待定` / `TBD` / 模板占位符）。操作：正则扫占位符模式族。
- **草稿 / 编辑 / 来源残留** — 内部批注、复制痕迹、模板拼接缝（编辑性短语如"定稿后删除/待确认"、拼接痕、编辑器残留）。操作：扫编辑性短语 + 拼接痕迹。
- **术语 / 专名变体** — 同一专名多种写法。操作：抽取专名，归一化比对。
- **单位 / 量纲不一致** — 同一量不同单位或量纲冲突。操作：抽取量纲，比对。
- **交叉引用断裂** — 引用的图表/章节/条款对不上或指向不存在处。操作：抽取引用，逐一回溯。
- **过期 / 时效失效** — 日期、有效期、版本号过期或自相矛盾。操作：抽取日期族，比对时效。
- **结构 / 编号机械项**（通用部分）— 编号断裂、图文/表文错位、孤立行——**只收任何文档都成立的机械项**；偏特定排版的特化项归鲁班当次图。
- **多源三角不一致** — 跨源同类值对不上。操作：跨源抽取同类字段，交叉比对。

**绑定的是偏差模式，不是某次漏报的具体值。** 某个具体数值矛盾是"内部数值矛盾"的实例，不是种子本身。种子换个检查域照样成立。

## 生长（候选机制，非会话内自动写库）

种子是冷启动的底。库靠**运行反馈**长，但**不在会话内自动改本文件**——那会违反判官"只攻不修"的核心设定，也违反会话隔离（本文件是工厂自身契约，不该被某次会话改）。改用候选机制：

1. 判官攻产物运行输出、或独立重读源输入时，发现一个**不属于已有任何一类**的新失败。
2. 判官**记入当次会话的 `failure-candidates.md`**（只记录：新偏差模式 + 实例 + 为何不属于已有类）——判官只记录，不修通用库，不违反"只攻不修"。
3. **会话结束后**，由**仓库维护者**（非当次会话用户）审查 `failure-candidates.md`，决定哪些值得**抽象掉域特征后沉淀**进本文件。
4. 沉淀是人工动作（更新本文件 + 版本号），不在任何会话的阶段里。

这是"可收敛的盲区"：判官和库都没记录过的偏差，**第一次会漏**（认识论极限）；但漏过一次，它进候选、人沉淀后进库，**不再漏第二次**。优于静态表（永不更新）和零散探针（永远靠运气）。人作为沉淀关卡，防"把域特定误当通用偏差塞进来"。

## 防污染（承重，写死）

- **通用库只收域无关类。** 判官记的候选，若剥不掉域特征，不沉淀进本文件——它归鲁班当次图。
- **不许把某次漏报原样塞进来当"通用偏差"。** 某个具体数值对、某个具体占位符串，是实例不是类。塞实例 = 补丁 = 虚假完备感（"表上都查了 = 干全了"）。
- 哪吒的守尖锐本能看见一长串就想瘦身——但这是价值验证骨，砍一项漏一类（见 `nezha.md`）。

## 它和鲁班图、判官的关系（参照单一）

- **鲁班**画 per-mission 图时，先按 skill 类型选偏差库（选择见 `bias-libraries.md`），**检查类引用本文件**作为反向轴的底（标注"见 failure-classes.md"，不复制内容），再推理域特定偏差轴。通用偏差是可迁移层，域轴是当次特化。
- **判官**攻运行输出时，逐类对照——通用偏差查本文件、域偏差查鲁班图。
- **覆盖殿** diff 参照 = 鲁班图（含对本文件的引用 ∪ 域轴）。本文件不另起 diff，通过鲁班图的引用 + 产物价值验证骨进入攻击面。
- **维护**：判官记候选（当次会话）；人沉淀（会话后，更新本文件）；鲁班引用 + 标域轴；哪吒不碰（承重清单）。

## 诚实的边界

- 库是 LLM 推理 + 运行反馈（经人沉淀）的产物，**不是真专家背书**。冷启动第一次会漏未知类。
- 它提高发现概率，**不保证发现**——判官和库都没记录过的全新偏差，首次仍有盲区。但保证漏过的不重漏（人沉淀后）。
- 因此收敛**不认"对任意实例有效"**，只认"可迁移偏差已绑定 + 在锚定样本上被带证据演示执行过（spawn 运行）"。实例是变的，生产期证不了普遍效能。
