# 偏差库（bias-libraries）注册

鲁班反向轴的源、判官攻产物运行输出的对照表。**库的机制类型无关，库的内容按 skill 类型注册**——每个类型一个偏差库，可插拔。

## 为什么按类型注册

偏差库不能只有一份全局库。一份库当全局用，装的实际是某一类的偏差模式——检查类的失败（数值矛盾、占位符残留、术语变体……）换个检查域照样成立，换到生成类/行动类就不成立（生成类的偏差是套路化、洞察停在表面；行动类的偏差是副作用、不可逆风险）。

把一份检查类特化当全局通用，等于"挑着用"——判官攻生成类产物时拿检查类偏差模式对照，攻不到点上。这是抽象没到家：**殿和骨的本质通用，判据/偏差按类型可插拔**。正确抽象不是把所有类型的偏差塞进一份库（那会污染、会稀释检查类的精确性），而是：

- **偏差库机制通用**（鲁班引用、判官对照、单一事实源、候选生长）——类型无关；
- **库内容按类型注册**——每个类型一份，类型特化，互不污染；
- **十殿/价值验证骨攻的是通用本质**，类型只决定"这一殿/这一骨拿什么判据攻"——判据来自对应类型的偏差库。

## 注册约定（写死）

1. **一个类型一份库**。类型集：检查/审计/校验/审查类、生成/创作类、行动/编排类（流程类归行动类，都是产出动作或状态变更）。新类型要扩展，先在此注册位声明。
2. **库只收该类型下域无关的通用偏差**——换具体业务/题材/场景照样成立的模式。域特定偏差归鲁班当次的 per-mission 图，不进库。
3. **每类偏差 = 偏差名 + 它是什么 + 怎么落地为一个操作**。落不了地的散文不算入库（治类目冒充操作，见 `skill-anatomy.md` 价值验证骨）。
4. **单一事实源**：通用偏差类的唯一权威是该类型的库文件。鲁班图只**引用**（标注"见 bias-libraries/<type>.md"，不复制内容）；判官对照时通用偏差查库、域偏差查鲁班图。一处源，不复制，不矛盾。
5. **生长走候选机制**（非会话内自动写库）：判官攻产物运行输出时发现新偏差 → 记入当次会话 `failure-candidates.md`（只记不修库）→ 会话后由仓库维护者审查、剥掉域特征后沉淀进对应类型库。防"把域特定误当通用偏差塞进来"，也防判官越权改库。
6. **防污染**：不许把某次具体漏报/失败原样塞进来当"通用偏差"。某个具体数值对、某个具体占位符串，是实例不是类。塞实例 = 补丁 = 虚假完备感。

## 类型与偏差库

| 类型 | 库文件 |
|---|---|
| 检查/审计/校验/审查 | `failure-classes.md`（种子见该文件） |
| 生成/创作 | `generation-bias.md`（种子见该文件） |
| 行动/编排（含流程） | `action-bias.md`（种子见该文件） |

## 三类之外的处置

当前类型集三类（检查/生成/行动），各有偏差库。架构对类型**通用**——十殿每殿攻通用本质、价值验证骨按类型开槽、偏差库机制类型无关。识别出**三类之外的新类型**（既非检查、非生成、非行动）时，判官没对照表可攻、鲁班没反向轴可引用、价值验证骨该类型槽空着——此时 `runtime_blocked`，指向"该类型不在当前类型集（检查/生成/行动）内、无对应偏差库"这个**可补的具体根因**，不许指向"架构不支持"。

阻塞的合法理由只能是"某类型不在当前类型集（检查/生成/行动）内"，不能是"架构只服务某一类"。前者可被"纳入类型集 + 注册其偏差库"消除——扩展一个新类型 = 解除该类型的阻塞，不需要动架构；后者是把范围锁死当永久承诺，同样是违宪第四条（诚实）。

## 它和鲁班图、判官、价值验证骨的关系

- **鲁班**画 per-mission 图时，先按 skill 类型引用对应偏差库作为反向轴的底（标注"见 bias-libraries/<type>.md"，不复制），再推理域特定偏差轴。通用偏差是可迁移层，域轴是当次特化。
- **判官**（覆盖向四殿）攻运行输出时，逐类对照——通用偏差查类型库、域偏差查鲁班图。
- **价值验证骨**（`skill-anatomy.md`）按类型开槽，每槽的"反向偏差子表"挂的就是该类型偏差库 + 鲁班域轴。
- **维护**：判官记候选（当次会话）；人沉淀（会话后，更新对应类型库）；鲁班引用 + 标域轴；哪吒不碰（承重清单，见 `nezha.md`）。

## 诚实的边界

- 类型库是 LLM 推理 + 运行反馈（经人沉淀）的产物，**不是真专家背书**。冷启动第一次会漏未知偏差类。
- 它提高发现概率，**不保证发现**——判官和库都没记录过的全新偏差，首次仍有盲区。但保证漏过的不重漏（人沉淀后）。
- 因此收敛**不认"对任意实例有效"**，只认"可迁移偏差类已绑定 + 在锚定样本上被带证据演示执行过（spawn 运行）"。
