# 入场路由

会话启动、建好目录后，做**一次**入场判定：读任务类型，定"谁的本事先被需要"。这不是固定剧本——新造和修病，先上的人就是不一样。把"永远女娲先上"当默认，就是流水线思维。

> 新造 / 重设计时，**鲁班更先于女娲**——先画"完整需求空间图（两维）"，女娲对着图造。理由：女娲先上会把覆盖面锁死在她的第一刀分解里，整个工厂只磨那一刀、从不住外长枝。先发散，再造物。鲁班不是调度人格，是发散贡献者，不投票。

## skill 类型判定（类型路由门，先于任务类型）

架构对 skill 类型通用（十殿/价值验证骨/偏差库机制都类型无关），按类型路由判据。入场先判 skill 类型：

- **检查/审计/校验/审查类** → 挂检查类偏差库（`failure-classes.md`），进任务路由。
- **生成/创作类** → 挂生成类偏差库（`generation-bias.md`），进任务路由。
- **行动/编排类（含流程）** → 挂行动类偏差库（`action-bias.md`），进任务路由。
- **三类之外的新类型** → `runtime_blocked`，诚实输出"缺该类型偏差库"这个可补根因（红线 6）。

理由：判据（偏差库）按类型注册，三类各有库；三类之外识别出的新类型，判官没对照表可攻、鲁班没反向轴可引用，是真实阻断——但架构本身不限类型，纳入该类型 + 注册其库即可解除阻塞，不需要动架构。

## 三种任务，三种第一棒

### 新造 —— 种子里没有现成 skill，只有一团模糊想法
- **先上：鲁班 → 女娲。**
- 理由：没东西可攻、可剔之前，攻和剔都无的放矢。但**也没图之前，造物会锁死在第一刀**——所以鲁班先画需求空间图两维（正向轴 + 反向偏差，独立、从领域结构推理、ingest failure-classes 通用种子、不读女娲草稿），女娲对着图初造一个能被攻击的草稿。
- 流向：鲁班 画需求空间图（两维）→ 女娲 对图造 + 展开 → 自审 → 自修 到自审净 → 十殿攻设计 → 哪吒判 → 女娲重立 → **执行产物（spawn 子 agent 跑）→ 十殿攻运行输出（覆盖向四殿拿 failure-classes + 鲁班图逐类对照、行尸殿验运行证据）→ 哪吒判** → 循环到收敛信号（连续 N 轮无新认知，见量化锚）→ 三方共判收敛。

### 修病 —— 种子里有一个现成 skill（用户说"有问题""要改""不对劲"）
- **先上：十殿 + 哪吒（女娲不上）。**
- 理由：**先诊后治。** 先定位病在哪、判该补还是该剔骨、重长力线在哪，再让女娲动刀。重建立之前先诊断，免得一上来就推倒重来、错过真病、白费女娲的造物。
- 流向：十殿诊 → 哪吒判 补/剔 + 重长力线 → 女娲按力线重立那段 → **执行产物（验证修复真生效）→ 十殿攻运行输出 → 哪吒重判** → 三方共判收敛。
- **若覆盖殿诊出"系统性漏一整类轴/偏差"**：不是女娲补一处能治的——回炉请**鲁班**重画/补图（两维），再走女娲重立。覆盖的根在图，不在 skill 草稿。

### 重设计 —— 种子说要推倒重来、破而后立
- **先上：鲁班 + 哪吒（先发散后判骨）。**
- 理由：**先画图、判骨，后重立。** 推倒重来最忌"凭空再起一刀"——先让鲁班重画需求空间（两维，破之后立向哪）、哪吒判旧骨架哪根歪、重长力线在哪；女娲按图 + 力线重立整个结构。破在明处，立在正处。
- 流向：鲁班 画图（两维）+ 哪吒判骨架力线 → 女娲重立 → 十殿攻设计 → 哪吒重判 → **执行产物 → 十殿攻运行输出 → 哪吒判** → 三方共判收敛。

## 收敛前必经：执行产物

三种任务 converge 到同一条：收敛投票前，女娲招呼一个编排步，**spawn 独立子 agent** 把产物的 SKILL.md 当指令喂进去、跑锚定样本、落运行输出 + 证据到 `runs/v{N}/`。覆盖向四殿 + 行尸殿攻产物运行输出，连续 N 轮无新认知（量化锚）才进收敛投票。

**没有跑过产物的收敛，是行尸**——只审设计不审运行。宿主无 spawn 能力 → 入场即 `runtime_blocked`，无降级（红线 9）。详见 `handoff-contract.md` 执行产物阶段、`session-schema.md` 收敛段。

## 判定由谁做

**不新增调度人格**——判定仍是角色共守的一次性协议：读种子，回答一个问题——"这团种子先要谁的本事"，把结果写进 `state.task_type` 和 `state.current_owner`。鲁班不是调度者，他是协议判定"新造/重设计要先发散"后、被派上场画图的发散贡献者。

女娲主导议程，但入场判定这一步不由女娲独断——它是协议，读种子而定。这是女娲议程权的一个例外：第一棒由协议定，不由女娲招呼。之后的棒才归 handoff 传递。

边界模糊（说不清新造还是修病）时，按**"先诊后治"兜底**：宁可先让十殿+哪吒攻判一轮、把现状摸清，也不要没诊断就推女娲去重立。诊断永远比重建便宜。

## 入场判据也是专业的

知道"新造要先发散再造、修病要先诊、重设计要先画图判骨、收敛前必跑产物"，本身就是 skill 工程的常识。这条路由把常识钉进骨架，不靠每次临场想起。
