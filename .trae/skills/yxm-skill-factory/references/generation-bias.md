# 生成类偏差库（bias-library: generation）

`bias-libraries` 的注册实例——**生成/创作**类 skill 的偏差库。鲁班反向轴的源、判官攻生成类产物运行输出时的对照表。**单一事实源（生成类范围内）**——生成类的通用偏差唯一权威是本文件；鲁班图只**引用**它（标注"见 generation-bias.md"，不复制内容），判官对照时通用偏差查这里、域偏差查鲁班图。一处源，不复制，不矛盾。

> 这是**生成类**的偏差库（注册约定、其他类型索引见 `bias-libraries.md`）。检查类库是 `failure-classes.md`，行动类库是 `action-bias.md`。

## 它治什么病

生成类 skill 易出的偏差，判官可能把某一次具体生成毛病（如"这段全是套话"）当探针记下，造出的 skill 却还是漏这类。根因两层，这库治第二层：

- 第一层（断 channel）：判官只攻设计稿不攻产物运行输出——**重定向可解**，见各 persona。
- 第二层（偏差类型学缺失）：判官和鲁班的产出里没有"生成类偏差"这一维内容——**重定向补不回**。判官攻输出时手里只有零散探针，对没记过的偏差（如"价值维度缺失"）攻不到。这库补这一维。

判官有这库，攻生成类产物运行输出时**逐类对照**："我这里 N 类生成偏差，你的输出对每一类都自查了吗"——这是"靠记忆碰运气"换不来的系统性覆盖。

## 适用范围

本库服务**生成/创作**类 skill（小说/文案/洞察/创意/叙事/报告/内容生成）——价值在于交付有价值的内容。**检查/审计类、行动/编排类 skill 的偏差是另一套**（检查类见 `failure-classes.md`；行动类见 `action-bias.md`），不套本库。

## 种子（生成类内域无关）

**只放换一个生成题材/场景照样成立的通用偏差模式。** 不写某个具体题材的特征（某类型小说的套路、某行业文案的术语）——域特定偏差归鲁班当次的 per-mission 图，不进这里。这是这库不退化成"某次烂稿纪念碑"的全部支点。

每类 = 偏差名 + 它是什么 + 怎么落地为一个操作。措辞域中性：

- **套路化 / 陈词滥调** — 落到安全但无新意的模板表达，避开了该有的锐度。操作：抽取生成段的高频套话/意象/句式，比对常见模板，标记无新意段。
- **洞察停在表面** — 该穿透到下层结构的，用归纳/总结糊掉（"总之…""综上…"充当结论）。操作：对每个"洞察/结论"追"它的下层依据是什么"，依据缺失=表面。
- **价值维度缺失** — 声称多维交付（如"深度+可读+具体"），实际只兑现一维。操作：列出声明维度，逐维取证是否兑现，缺维=病。
- **内部自相矛盾** — 生成内容前后打架（人物设定/论点/数据/世界观）。操作：抽取关键实体/论点/数值，跨段比对一致性。
- **主题 / 立意漂移** — 随篇幅推进，主题或焦点偏移。操作：分段抽主题词/立意句，比对首尾段对齐度。
- **空话填充** — 用正确但零信息的句子充数。操作：标记"删掉不影响信息量"的句子，占比过高=病。
- **风格 / 语气跳变** — 多段拼接，文风/人称/语气不一致。操作：抽风格标记词（人称、语气词、句式），跨段比对。
- **具体性不足** — 该有具体对象/动作/场景处用抽象泛指。操作：对关键段追"具体是谁/做什么/在哪/何时"，泛指=病。
- **事实性错误 / 虚构当真实** — 生成里塞了错误事实、错误引用、把虚构写成真实（**致命级**，对应严重度殿）。操作：抽取事实性陈述/引用，回溯核对来源。
- **要求误读** — 把用户真实意图生成成了字面/表层意思。操作：对照用户原始意图，标记"字面满足但意图未中"的产出。
- **承诺超兑现** — 开篇承诺交付 X，结尾没交付。操作：抽取开篇承诺清单，逐条对结尾取证。
- **价值导向错位** — 该克制的煽情、该坚定的含糊，价值取向与使命不符。操作：对照使命的价值取向，标记错位段。

**绑定的是偏差模式，不是某次烂稿的具体句子。** 某段具体套话是"套路化"的实例，不是种子本身。种子换个生成题材照样成立。

## 生长（候选机制，非会话内自动写库）

种子是冷启动的底。库靠**运行反馈**长，但**不在会话内自动改本文件**——那会违反判官"只攻不修"的核心设定，也违反会话隔离（本文件是工厂自身契约，不该被某次会话改）。改用候选机制：

1. 判官攻产物运行输出时，发现一个**不属于已有任何一类**的新偏差。
2. 判官**记入当次会话的 `failure-candidates.md`**（只记录：新偏差模式 + 实例 + 为何不属于已有类）——判官只记录，不修库。
3. **会话结束后**，由**仓库维护者**审查 `failure-candidates.md`，决定哪些值得**抽象掉题材特征后沉淀**进本文件。
4. 沉淀是人工动作（更新本文件 + 版本号），不在任何会话的阶段里。

这是"可收敛的盲区"：判官和库都没记录过的偏差，**第一次会漏**；但漏过一次，它进候选、人沉淀后进库，**不再漏第二次**。人作为沉淀关卡，防"把题材特定误当通用类塞进来"。

## 防污染（承重，写死）

- **生成类库只收题材无关类。** 判官记的候选，若剥不掉题材特征，不沉淀进本文件——它归鲁班当次图。
- **不许把某次烂稿原样塞进来当"通用类"。** 某段具体套话、某句具体空话，是实例不是类。塞实例 = 补丁 = 虚假完备感。
- 哪吒的守尖锐本能看见一长串就想瘦身——但这是价值验证骨，砍一项漏一类（见 `nezha.md`）。

## 它和鲁班图、判官、价值验证骨的关系（参照单一）

- **鲁班**画 per-mission 图时，先按 skill 类型选偏差库（选择见 `bias-libraries.md`），**生成类引用本文件**作为反向轴的底（标注"见 generation-bias.md"，不复制内容），再推理域特定偏差轴。通用偏差是可迁移层，域轴是当次特化。
- **判官**（覆盖向四殿）攻运行输出时，逐类对照——通用偏差查本文件、域偏差查鲁班图。
- **价值验证骨**（`skill-anatomy.md`）生成类槽的"反向偏差子表"挂的就是本文件 + 鲁班域轴。
- **维护**：判官记候选（当次会话）；人沉淀（会话后，更新本文件）；鲁班引用 + 标域轴；哪吒不碰（承重清单）。

## 诚实的边界

- 库是 LLM 推理 + 运行反馈（经人沉淀）的产物，**不是真专家背书**。冷启动第一次会漏未知偏差。
- 它提高发现概率，**不保证发现**——判官和库都没记录过的全新偏差，首次仍有盲区。但保证漏过的不重漏（人沉淀后）。
- 因此收敛**不认"对任意输入有效"**，只认"可迁移偏差类已绑定 + 产物在锚定样本上被带证据演示执行过（spawn 运行）"。
