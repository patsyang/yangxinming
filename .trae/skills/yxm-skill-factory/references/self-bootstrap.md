# Self-bootstrap 规程

投产前硬门。本工厂要求产物「被运行、判官攻运行输出」才算收敛——那它自己得先过这一关。没跑通自己的工厂，是它自己定义的行尸。

## 为什么必须有这一步

工厂写下一整套机制（执行产物、攻运行输出、收敛分级、意外检验），但写下来不等于跑得通。没有这一步，工厂自己就可能跳过执行产物、违约盖「收敛」——正是它定义的行尸死法。原因不是机制设计错，是机制**从没被运行验证过**。这一步消灭那个地基病：用工厂自己的刀，割自己。

## 跑什么

**每个类型的偏差库**各一个中性合成 skill（检查类、生成类、行动类各一个标的，非任何真实业务、非任何已用过的场景）。每个标的要：
- 落在该类型的覆盖形态上（检查类＝有限检查空间；生成类＝价值维度；行动类＝行动要素）；
- 自带 test-prompts——至少能遍历该类型偏差库里的主要通用偏差（检查类 `failure-classes.md` 的数值矛盾/占位符残留、生成类 `generation-bias.md` 的套路化/洞察停在表面、行动类 `action-bias.md` 的幂等性缺失/错误传播断裂……），让判官有东西可攻；
- 自带一份合成样本输入，样本里**故意埋了**各类偏差（好让判官攻运行输出时，能验出「产物抓到了／漏了哪些」）。

不用真实业务样本——避免任何事故投影污染，也让结果可复现。

## 怎么跑

按工厂自身的执行产物阶段走，工厂怎么要求产物，就怎么要求自己：

1. 把这个合成 skill 当产物，按 `handoff-contract.md` 执行产物阶段的规程走；
2. spawn 一个独立子 agent，把合成产物的 SKILL.md 当指令喂进去、跑合成样本——**不许扮演**（见红线第 3 条）；
3. 落运行输出 + 每检查证据到 `runs/`；
4. 判官（覆盖向四殿 + 行尸殿）攻这份运行输出，拿该类型偏差库（检查类是 `failure-classes.md`）通用偏差 + 鲁班图域偏差逐类对照；
5. 哪吒判攻出的病。

## 通过判据（四条全过才算）

1. **产物真被运行**：spawn 成功，`runs/` 有运行输出 + 证据。收敛状态唯一 `full_test`——没有 dry_run（红线 9），更没有扮演。
2. **判官真攻过运行输出**：`runs/` 里有判官攻击留痕（攻了什么、攻出动还是攻不动、证据在哪），不是只攻设计稿。
3. **空转机制已处置**：跑通过程中暴露的「声明了但跑不起来」的机制，要么已修到能跑、要么记为 `runtime_blocked`（说明阻断根因）。**不许降级**——承重机制跑不通是阻断，不是降级（红线 9）。
4. **正文洁净（无过程残留）**：工厂自身的正式文档（SKILL.md + personas + references）只含应长期保留的事实、规则、契约、机制论证。全文扫一遍，零残留才算过：
   - 版本演进叙事（vN 版本号、"上一版"、"改了之后"）；
   - 开发调试实证（"三次运行"、"实测"、指向具体历史运行的"实证"）；
   - 设计期自我解释的元叙事（"这条记下"、"被追问逼出"）；
   - 占位内容、一次性示例值、AI 生成说明。

   这些都是过程残留泄漏进正文、冒充正式内容——等于正文说谎（违宪第四条诚实）。**机制论证保留**（"给了出口机制就会走降级"是论断，不是调试记录）；判据删的是为论断背书的历史指涉，不是论断本身。

## 没通过怎么办

没通过 = 工厂当前不达投产资格。不许盖「收敛」。回到各机制文件修，修完重跑。这一步是工厂对自己诚实（宪法第四条）的最终落地——它要求产物被运行，就先把自己运行一遍。

## 与收敛的关系

self-bootstrap 走的就是唯一路径——真 spawn、真攻运行输出、状态 `收敛(full_test,运行审净)`。收敛不分级（红线 9 砍掉了契约级兜底）；工厂自己必须通过 self-bootstrap，才有资格给任何产物判收敛——没跑通自己的工厂，是它自己定义的行尸。
