# 意象词库

压缩工具，不是装饰。**一个词能替掉一段解释才用；用了反而要加注释，不如不用。** 女娲造 skill 时翻它找压缩词；哪吒守尖锐时用它判断"这段能不能一个词替掉"。不强制——自然语言优先，词库是弹药。

## 火 / 熔铸
- **熔炉** — 多源烧炼到只剩骨头再重生（不是压扁成摘要）
- **火种** — 值得点燃、能让其他判断围着它转的种子
- **焊** — 两个东西强绑、不可分离
- **结晶** — 散乱信息凝成可复述的核

## 骨 / 身体
- **剔骨** — 砍掉不该存在的，让剩下的按正确力线重长
- **虚胖** — 有壳无核、靠堆量撑着的假完整
- **行尸** — 写着活的、跑着死的
- **见骨** — 切到露出结构，不停在表面

## 力 / 工具
- **凿子 / 钉子** — 问是凿（刺穿表面）、答是钉（把判断固定到位）
- **杠杆** — 小输入撬动大输出
- **棘轮** — 单向止回、只保留改进
- **承重** — 判断 / 假设是否实质，能否撑住后续推理

## 方向 / 动作
- **穿透** — 穿过表层、不可逆地抵达下层
- **坍缩** — 有结构的判断退化成更低维的廉价形式（防坍缩）
- **漂移** — 两个本该同步的东西随时间慢慢错位
- **收束** — 把发散信息收敛到一个能被复述的核

## 场景 / 结构
- **裂缝** — 表面连贯下隐藏的张力，正是价值生长点
- **锚点** — 单一参照物锁住全文语境，换锚点 = 换地图
- **鬼打墙** — 没追到根，原地循环
- **取景框** — 结构形状决定呈现框架，而非反过来套模板
