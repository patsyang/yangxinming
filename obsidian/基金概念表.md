# 基金概念表

## 一、基金基本类型

| 概念 | 一句话解释 |
|------|-----------|
| 基金 | 大家凑钱交给专业的人去投资，赚了按份额分，亏了一起扛 |
| 货币基金 | 主要投资短期债券和银行存款，几乎不亏，年化收益约 1.5-2%，余额宝就是这类 |
| 债券基金 | 80%以上资产投资于债券，收益稳（年化约 3-6%），波动小 |
| 股票型基金 | 80%以上资产投资于股票，涨得猛跌得也猛，波动大 |
| 混合型基金 | 股票和债券都买，比例灵活，风险和收益介于股基和债基之间 |
| 指数基金 | 跟踪特定指数（如沪深300），不依赖基金经理个人判断，费率低 |
| QDII 基金 | 合格境内机构投资者基金，用人民币买，帮你去海外市场投资（美股、港股等） |
| FOF 基金 | Fund of Funds，基金中的基金，买的是其他基金而不是直接买股票/债券 |

---

## 二、指数基金细分

| 概念 | 一句话解释 |
|------|-----------|
| 宽基指数 | 覆盖全市场各行业的指数，行业分散，是定投首选（如沪深300、中证500、中证1000） |
| 行业/主题指数 | 聚焦某个行业或主题的指数，波动大（如新能源、医药、半导体、消费） |
| 指数增强型 | 在跟踪指数基础上适度主动管理，力争跑赢指数 |
| ETF（场内基金） | 像股票一样在证券交易所实时买卖，价格每分钟变动，费率最低 |
| ETF联接基金 | 在支付宝/天天基金等平台申购赎回，按 T+1 净值成交，跟踪场内 ETF |
| LOF（上市开放式基金） | 既可以在场外申购赎回，也可以在场内像股票一样买卖 |

## 三、核心指标

| 概念 | 你需要知道的 |
|------|-------------|
| 单位净值 | 一份基金当前值多少钱，每个交易日收盘后计算并于当晚公布，不是实时变动的 |
| 累计净值 | 单位净值 + 基金历史上所有分红之和，反映基金成立以来的总收益 |
| 份额 | 你持有的基金数量 = 买入金额 ÷ 买入时净值 |
| 规模 | 基金管理的总资产规模，≥50亿较安全，<2亿有清盘风险 |
| 最大回撤 | 历史上从最高点到最低点的最大跌幅，反映最坏情况下的亏损幅度 |
| 跟踪误差 | 指数基金净值偏离对应指数的程度，越小越好（年化≤0.3%为佳） |
| 夏普比率 | 每承担一单位风险获得的超额收益，越高越好，但需同类型比较 |
| 换手率 | 基金一年内买卖股票的频率，反映基金经理调仓活跃度 |
| 同类排名 | 在同类基金中的收益排名，四分位分为优秀/良好/一般/不佳 |

## 四、费用相关

| 概念 | 你需要知道的 |
|------|-------------|
| 申购费 | 买入时收取的手续费，平台通常打1折（约0.1%-0.15%） |
| 赎回费 | 卖出时收取的手续费，持有时间越短越贵（持有<7天通常1.5%，>2年免收） |
| 管理费 | 基金公司收取的管理费用，从基金资产中每天计提，你看不到直接扣 |
| 托管费 | 银行收取的资金托管费用，从基金资产中每天计提，你看不到直接扣 |
| 销售服务费 | C类份额按日计提的费用，替代申购费，适合短期持有 |
| A类份额 | 前端收费模式，买入时收申购费，长期持有（>1年）更划算 |
| C类份额 | 不收申购费，按日计提销售服务费，适合短期持有（<1年） |
| D类份额 | 部分平台或直销渠道专属份额，费率通常更低 |

## 五、交易规则

| 概念 | 你需要知道的 |
|------|-------------|
| 交易时间 | 每个交易日（周一至周五，节假日除外）9:30-15:00 |
| 15:00 规则 | 交易日15:00前下单按当天净值成交，15:00后按下个交易日净值 |
| 周末/节假日 | 在周末或节假日下单，算节后第一个交易日的申请 |
| T日 | 你提交申购/赎回申请的交易日 |
| T+1 | 下一交易日确认份额（货基快速赎回可能T+0） |
| 赎回到账时间 | 货基T+1/T+2、债基T+2/T+3、股基/混合T+3/T+4、QDII T+7-T+10 |
| 定投 | 定期定额投资，自动扣款买入 |

## 六、基金信息术语

| 概念 | 你需要知道的 |
|------|-------------|
| 基金经理 | 负责管理基金投资运作的人，看其从业年限和过往业绩 |
| 基金公司 | 发行和管理基金的公司 |
| 托管人 | 保管基金资产的银行或机构，监督基金公司运作 |
| 成立日期 | 基金首次募集完成的日期 |
| 业绩比较基准 | 基金设定的收益目标参考线（如"沪深300指数收益率×80%+中债指数收益率×20%"） |
| 分红 | 基金将部分收益以现金或再投资形式分配给持有人 |
| 拆分 | 基金净值除以N，份额乘以N，总资产不变，目的是降低净值吸引投资者 |
| 建仓期 | 新基金成立后买入股票/债券的时期，通常不超过3个月 |
| 封闭期 | 基金成立后不接受申购赎回的期间，封闭式基金在整个存续期内都不能赎回 |
| 定期开放 | 一段时间开放申购赎回，之后又进入封闭期（如"一年持有期"基金） |
| 限购 | 基金限制申购金额或份额，通常是规模太大或为了保护持有人利益 |
| 清盘 | 基金规模连续60个工作日低于5000万元或触发其他条件时被终止，资产清算后返还给持有人 |
| 持仓/投资组合 | 基金持有的股票、债券等资产明细，定期报告披露 |

## 七、收益相关

| 概念 | 一句话解释 |
|------|-----------|
| 日增长率 | 基金当天的涨跌幅 |
| 阶段涨幅 | 指定时间段内的累计涨幅（如近1月/近1年/近3年等） |
| 成立以来收益 | 基金从成立至今的总收益率 |
| 年化收益 | 将收益折算成每年的平均收益率，方便跨期限比较 |
| 七日年化 | 货币基金专用，过去7天的平均收益折算成年化收益率 |
| 万份收益 | 货币基金专用，每1万份基金当天实际赚多少钱 |

## 八、风险等级

| 概念 | 你需要知道的 |
|------|-------------|
| R1（低风险） | 货币基金、部分债券基金，本金几乎安全 |
| R2（中低风险） | 纯债基金、短债基金 |
| R3（中风险） | 混合基金、可转债基金、部分指数基金 |
| R4（中高风险） | 股票型基金、行业指数基金 |
| R5（高风险） | 杠杆基金、衍生品基金、QDII（投资海外股票/新兴市场） |
